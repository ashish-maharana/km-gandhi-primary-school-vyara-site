# K.M. Gandhi Primary School Website

Static Next.js (App Router) + Tailwind CSS website for:
- શ્રી ખુશાલદાસ મકનદાસ ગાંધી પ્રાથમિક શાળા
- Vyara, Tapi, Gujarat, India

## Stack
- Next.js App Router + TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React icons
- Fully static export (`output: "export"`)

## Run Locally
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```

## Notes
- Standalone school site under `D:\www\demo-sites`.
- Placeholder-only imagery and logo are used until official school assets are provided.
- Contact values, class range, principal details, and facility counts should be verified before production.
